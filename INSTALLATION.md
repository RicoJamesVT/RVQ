Quick install instructions

- Android (Chrome): Open the game in Chrome on Android. If a prompt appears, tap "Install". If not, tap the "Install Game" button in the top-right to open the install prompt.

- iOS (Safari): Tap the "Install Game" button and follow the instructions: tap the Share icon then choose "Add to Home Screen".

- Desktop: The game is playable in-browser. Use the browser's menu (Chrome: "Install App" or "Create shortcut"; Edge: "Install this site as an app") for a more app-like experience.

Notes
- The game works offline using the included service worker if served over HTTP(S) and a service worker is registered.
