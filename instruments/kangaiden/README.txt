KANGAIDEN — Shadow of the Shogun

Controls
--------
Desktop keyboard:
  A / Left Arrow   Move left
  D / Right Arrow  Move right
  Space / W / Up   Jump
  J                Slash
  K                Shuriken
  S / Down Arrow   Crouch
  R                Restart after defeat

Gamepad / controller:
  Left Stick / D-pad Left/Right  Move
  D-pad Down / Left Stick Down   Crouch
  A / Cross                      Jump
  X / Square                     Slash
  B / Circle                     Shuriken
  Start / Options                Restart after defeat

The controller uses the browser's standard Gamepad API and supports Xbox,
PlayStation and most generic USB/Bluetooth gamepads. Keyboard, gamepad and
touch controls can all be used by the same build. Supported controllers may
also provide vibration feedback for attacks, hits and player damage.

Mobile / tablet:
  On-screen touch controls appear automatically on coarse-pointer/mobile
devices. The game supports both portrait and landscape layouts.

Boss
----
Every 5th wave is a BoomBox Titan boss battle using boombox_boss_atlas.png.
The boss has a dedicated health bar, contact damage and a ground shockwave.

Offline
-------
The game is self-contained and uses inline/generated audio and local sprite
assets, so it can run offline once the files are opened locally or served
from a local/static host.
