# Rico's Filter Lab

Standalone Web Audio API filter module for Rico's Vinyl Quest.

## Run
Open `index.html` in a modern browser. Press START to unlock audio.

## Drop into game.js
The app is intentionally dependency-free. The `<main class="lab">...</main>` UI and the JavaScript audio section can be moved into a mini-game/module container in your existing game.js.

Controls:
- Cutoff
- Resonance
- Drive
- Dry/Wet
- Low-pass / High-pass / Band-pass
- Start/Stop
- Randomize
- Touch/mouse controls
- Space = start/stop
- R = randomize

No external libraries or network requests are required.
